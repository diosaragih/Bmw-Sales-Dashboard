# BMW Sales Dashboard

This project is a simple dashboard to explore BMW sales data using Excel and Power BI.

I built this to practice how to turn raw data into something easier to understand. The focus here is not on complex analysis, but more on getting comfortable with data visualization and finding basic insights.

## Tools
- Excel
- Power BI

## Dataset
The dataset includes information about car models, sales, revenue, regions, and other supporting details.

## Data Columns
- Model → Car model
- Year → Year of sale
- Region → Sales region
- Color → Car color
- Fuel_Type → Type of fuel
- Transmission → Transmission type
- Engine_Size_L → Engine size in liters
- Mileage_KM → Distance traveled (km)
- Price_USD → Price per unit
- Sales_Volume → Number of units sold
- Sales_Classification → Sales category
- Revenue → Total revenue (Price × Sales Volume)

## Key Insights
- Sales change over time and show some peaks in certain years.
- Some models clearly contribute more to total sales.
- Hybrid cars seem to have a noticeable share compared to other fuel types.
- We can also see customer preferences from color distribution.

This project is still very basic and focuses on visualization rather than deep analysis.
